# Hi, I'm Ahbab

I build smart contracts and the apps around them, mostly DeFi and NFTs, using Solidity and Foundry. I care a lot about security, so I spend as much time trying to break my contracts as I do writing them.

## Things I've built

**[Solvent Protocol](https://github.com/AhbabSameer/Solvent-protocol)** · [Live demo](https://solventprotocol.netlify.app)

A lending protocol that works like a pawn shop run by a smart contract. Deposit collateral, borrow against it, and if your position gets risky, anyone can liquidate it. Includes Chainlink oracles with staleness checks, unit, fuzz, invariant, and reentrancy tests, and static analysis with Slither and Aderyn.

**[NFTrium](https://github.com/AhbabSameer/NFTrium)** · [Live demo](https://nftriumm.netlify.app)

An NFT marketplace where you can mint, sell at a fixed price, or run an auction. Late bids extend the auction so nobody gets sniped, listings are held in escrow, and creators earn royalties on every resale.

**Also built:** an overcollateralized stablecoin, a cross-chain rebase token with Chainlink CCIP, ERC-4337 account abstraction, and some [security review reports](https://github.com/AhbabSameer/Security-audits).
